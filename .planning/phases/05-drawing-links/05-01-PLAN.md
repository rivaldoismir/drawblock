`src/services/linkTarget.ts`:
```ts
export type LinkTarget =
  | { kind: "drawing"; path: string }
  | { kind: "note"; path: string }
  | { kind: "external"; href: string }
  | { kind: "invalid"; reason: string };

export function encodeHref(path: string): string;   // spasi → %20, jangan encode "/"
export function decodeHref(href: string): string;   // decodeURIComponent yang aman (try/catch)
export function resolveHref(notePath: string, href: string): LinkTarget;
export function drawingHref(notePath: string, drawingPath: string): string; // relatif terhadap folder catatan
```
Aturan: `http:`, `https:`, `mailto:`, `tel:`, `#` → `external`; href absolut/`file:` → `invalid`; selain itu resolve relatif terhadap `parentPath(notePath)` dan normalisasi `..`/`.`; hasil di luar root atau mengandung `..` sisa → `invalid`. Ekstensi `.excalidraw` → `drawing`; `.md` → `note`; lain → `invalid`.

Tes: `drawingHref("a/b.md", "a/b/New 1.excalidraw")` → `New%201.excalidraw`; resolve balik → `a/b/New 1.excalidraw`; `../x.excalidraw` dari subfolder; `https://…` external; `#anchor` external; `%2e%2e/` tidak bisa keluar root.
